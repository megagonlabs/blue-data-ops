## Projection behavior

Each nonempty group produces a typed union of the fields found in its records. The schema and `projection_instructions` leave the process when a real provider is used. The reply must map names in that schema to unique nonblank output names. An empty object validly selects no columns. Non-mappings, unknown source names and duplicate destinations fail as malformed replies.

Output records are new dictionaries. Selected nested values retain their identity. Empty outer input, an empty first group, or blank instructions returns raw `[]` without resolving a client. Later empty groups remain empty. `run()` contains provider and parsing failures; raw calls expose them after retries. The current `output_attributes` mapping is empty.

Caller prompt, extraction, and transport controls are reserved, including null or
copied defaults. Dollar placeholders are substituted once; inserted data and Jinja
syntax stay literal. Define custom prompts in trusted operator defaults. Injected
clients retain generation settings, while operator prompt/extraction defaults win.

### Strict response handling

Replies must map existing schema names to unique nonblank string destinations. Unknown source names and duplicate destinations are rejected. An empty object selects no columns and remains valid. Malformed replies fail through `run()` with `exec_meta.errors`; raw `apply()`/`invoke()` raise.
